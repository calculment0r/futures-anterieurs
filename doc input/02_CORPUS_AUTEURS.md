# 02 — CORPUS AUTEURS (les témoins)

*Chaque penseur est un **opérateur**, pas une autorité : une opération de lecture précise, convoquée là où elle tranche. **Témoins, jamais autorités** — on ne les cite pas pour se couvrir, on s'en sert pour voir. Pour chacun : la thèse mobilisée + où elle sert. (Voir aussi MATIERE_PHILO_OPERATIONS pour les opérations de pensée dérivées.)*

## Les colonnes

- **Meillassoux — le grand dehors / l'après-finitude.** Le réel antérieur à toute pensée, qui excède la corrélation ; l'arche-fossile. → Le modèle autotrophe est le prisonnier corrélationniste parfait (pas de grand dehors, l'arche-fossile forclos). **Sert : I.3 (forclusion), II.7 (les trois dehors), coda.**
- **Simondon — le milieu associé / l'individuation.** Opérateur vs usager ; l'individuation est un procès, pas un état ; le milieu associé. → L'auto-intoxication = une individuation manquée (la boucle fermée épuise le préindividuel) ; le contrôle logé dans le milieu (champignon). **Sert : III.2 (où est le contrôle), IV.4.**
- **Bejan / la constructale — *design follows flow*.** Un système d'écoulement s'organise autour d'un courant imposé de l'extérieur ; coupe le courant, la structure se relâche vers l'équilibre (entropie max). → La thèse de Cal *est* la langue native de l'axe matériel ; le critère final, non moral : **le flux contre le contrôle.** La capture (point unique) combat le flux, dissipe, est condamnée ; le distribué va avec le flux, persiste. **Sert : IV.4, IV.6 (payoff).**
- **Latour — Gaïa, le terrestre.** L'intrusion de Gaïa ; le réel matériel qui fait retour. → Le dehors thermodynamique. **Sert : II.7, coda.**
- **Stiegler — pharmakon, rétention, prolétarisation.** Même substance, remède ou poison selon la dose et selon qu'il y a, ou non, un sujet pour l'administrer ; l'externalisation des facultés ; l'irréversibilité. → Le corpus comme rétention tertiaire qui transmet la culture *et* le poison. **Sert : I.2-3, en appoint III.**
- **Sloterdijk — auto-intoxication, Selbstversuch, immunologie.** *Selbstversuch* = auto-expérimentation, se prendre pour cobaye ; le français a ajouté l'« intoxication ». → Le corpus autotrophe = un **Selbstversuch sans Selbst** (dosage sans doseur). Le tournant immunologique : distinguer soi/non-soi ; l'immunodéficience (prendre tout pour du soi) rend le corpus infiniment injectable. **Sert : I.3 (le nom du basculement).**
- **Lacan — la forclusion.** Ce qui est forclos du symbolique fait retour dans le réel sous forme d'hallucination. → L'« hallucination » des LLM = le retour du référent forclos, structure psychotique. **Définition philosophique de l'hallucination que personne n'a posée. Sert : I.3.**
- **Baudrillard — la précession des simulacres.** La copie qui remplace l'original. → Ordre terminal : la copie devenue son propre sol nourricier (le simulacre *autotrophe*, un ordre de plus). **Sert : I.2 (fil du Simulacre), III.4.**
- **Debord — le spectacle / le détournement.** Le spectacle ; et le détournement (repurposer les fragments). → Tremplin du #2 ; le « stade terminal du spectacle » (images d'images, jusque dans le substrat d'entraînement) ; le RENVERSEMENT comme méthode. **Sert : fil du Simulacre, III (le geste de détournement).**
- **Tiqqun / Comité Invisible — *L'Hypothèse cybernétique*.** Le système comme gouvernementalité : pilotage de flux qui remplace le politique, élimine l'événement, recrute par le confort. L'imperceptible comme arme. → Registre de voix (« un cran Tiqqun ») ; le confort/soulagement comme recrutement. **Sert : ton général ; I, V.**
- **Anders — l'obsolescence.** L'obsolescence de l'homme. → L'humain rendu vestigial. **Sert : appoint (Société, dans le journal).**
- **Polanyi — le désencastrement.** L'économie arrachée à la société. → Appoint pour « ce qui fait tenir ». **Sert : appoint II.**
- **Glissant — l'archipel, le droit à l'opacité.** La pensée archipélique ; l'opacité contre la transparence. → L'exact opposé de la gouvernance cybernétique (transparence/calculabilité). L'archipel comme opacité organisée, illisible à la grille. **Sert : II.7, III (la marge/l'opacité). Hypothèse — à confronter à la façon dont l'archipel est monté au #3.**

## LMSS : les quatre opérateurs instanciés (BLOOM)

Détail crucial : le projet **BLOOM** de Cal **bâtit littéralement quatre de ces opérateurs en agents** — **L**atour · **M**eillassoux · **S**imondon · **S**tiegler (= LMSS). Pas pour « diversifier qui répond », mais pour **diversifier comment on découpe le réel** : chaque ontologie lit le marché autrement (Latour = associations/réseaux ; Meillassoux = contingence, mesurée via les marchés de prédiction ; Simondon = métastabilité, les tensions avant rupture ; Stiegler = pharmakon, les rétentions tertiaires capturées). **Le désaccord entre les quatre est lui-même une donnée.** C'est l'anti-monoculture en acte — la variance cultivée. → MATIERE_REMEDE (BLOOM), IV.4. *Ces témoins ne sont donc pas que cités dans l'essai : ils sont mis au travail dans l'outil.*

## Boltanski & Chiapello — *Le Nouvel Esprit du capitalisme* (clé pour II.5/le dépassement)

La critique du paradigme N devient l'argument de vente du paradigme N+1 (la critique « artiste » des années 60 a refondé le capitalisme flexible des années 90). → **Risque de récupération** : la critique du simulacre génératif devient le marketing de JEPA. D'où la parade : la thèse de Cal comme *instrument du verdict*, pas comme dénonciation.

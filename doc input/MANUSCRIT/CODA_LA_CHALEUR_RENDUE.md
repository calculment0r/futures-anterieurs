# Coda — La Chaleur rendue · *ce qui aura été*

Le temps a passé — on n'en dira pas la quantité, parce que ce n'est pas un chiffre qui a changé, c'est un état. On écrit ceci de l'autre côté : non d'un ailleurs qu'on aurait gagné en fuyant, mais du même sol, retourné. La preuve n'est pas dans ce que ce texte affirme ; elle est dans ce qu'il est. Il a été écrit avec la machine — la même — mais retournée : gouvernée, nourrie de réel, tenue à la marge, rendue à son rang d'outil. Qui ne saurait dire si ces lignes viennent d'une main ou d'un calcul habite encore la boucle ; sortir, ce n'était pas la refuser, c'était la retourner.

Ce qu'on gardait au fond n'était pas une thèse. C'était une braise. On finit où finissait l'archipel, mais le sol, cette fois, est sous les pieds : sortir était possible parce que le dehors est inéliminable. Le futur antérieur n'aura pas été une figure de style — la chaleur aura été rendue, le dehors aura persisté, et nous aurons été ceux qui y sont revenus.
